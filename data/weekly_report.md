# 每周市场总结与下周展望（2026年8月7日）


## 一、本周复盘

**市场整体表现：** 本周美股呈现高位震荡格局。标普500最新报7709.96点，距52周高点仅回撤0.34%，周内曾短暂冲高后回落。纳斯达克100报29373.33点。值得关注的是，周四（8月6日）道指单日下跌464点，主要受软件股集体下挫拖累（Datadog暴跌19%），但芯片股在盘中出现分化反弹。VIX报15.15，处于相对低位，市场整体风险偏好尚可，情绪指标读数66.2（贪婪区间）。

**核心驱动因素：**

1. **地缘政治风险升温：** 伊朗在霍尔木兹海峡问题上的态度趋于强硬，提出限制性草案，直接推升WTI原油至78.18美元/桶。海峡通行近乎停滞的报道加剧了供应中断担忧，能源板块获得支撑。这是本周市场最主要的宏观扰动项。

2. **AI资本开支"疲劳"与债券融资并行：** Alphabet宣布上调2026年资本开支预测后，随即启动250亿美元债券发行（10批次），凸显超大规模云厂商在AI军备竞赛中对资金的渴求。市场对"AI Capex何时兑现回报"的质疑声渐起——Jamie Dimon公开表达了对AI资本开支回报周期的关注，Anthropic在60天内通过SPV累积710亿美元芯片租赁债务的消息进一步放大了这一焦虑。

3. **存储芯片板块业绩"利好出尽"：** Sandisk和Western Digital财报数据本身强劲（Sandisk宣布140亿美元回购），但指引未能达到投资者已抬高的预期，引发存储芯片板块大幅回调——Sandisk周跌6.81%，SK Hynix跌4.97%。Micron相对抗跌（仅跌1.31%），在盘中收复大部分跌幅。这一事件暴露了AI存储交易拥挤度过高的风险。

4. **美联储降息预期博弈：** 市场在等待周五（8月7日）公布的7月非农就业报告，此前美股已连续五个交易日上涨，投资者在数据公布前趋于谨慎。10年期美债收益率报4.67%，2年期实际利率约1.95%，利率水平仍对估值构成压制。
