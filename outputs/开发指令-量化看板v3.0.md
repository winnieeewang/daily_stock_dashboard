## 1. 数据层修正

### 1.1 FRED 指标修正（utils.py）

**现状**：4 张指标卡已接入 FRED（DGS2 / GFDEBTN / MDEBT / NFCILEVERAGE），其中杠杆子指数已用 `NFCILEVERAGE`（非 NFCI 总指数），符合要求。

**新增（已完成）**：
- `fetch_2y_scorecard()` 增加 `real_y2` 字段 = **DGS2 − T5YIE**（5Y 盈亏平衡通胀近似 2Y 实际利率），返回结构含 `real_y2_note: "近似（DGS2−T5YIE）"`。
- Dashboard「2-Year Scorecard」卡内新增一行：`实际利率(2Y): x.xx% ≈DGS2−T5YIE`。
- **验收**：FRED key 配置后，2Y 卡同时显示名义利率与近似实际利率；无 key 时显示"数据待接入"。

### 1.2 FINRA 保证金债务自动抓取（utils.py + stock_dashboard.py）

**根因**：原实现 `_fetch_finra_margin()` 要求手动下载 `finra_margin.csv`，缺失时显示"需手动下载"，无法自动化。

**修复（已完成）**：
- `utils.fetch_finra_margin_web()`：直接抓取 FINRA 官网 margin-statistics 页面 HTML 表格（`pandas.read_html`），返回最新月份 Debit Balances（百万美元 → 十亿美元）。官网无 API feed，这是唯一自动途径。
- `utils.fetch_margin_debt()`：FRED MDEBT 为主源 + FINRA 官网交叉校验（返回 `finra_web_value` / `finra_web_month`）；无 FRED key 时自动降级为官网直抓。
- `stock_dashboard.MacroCollector._fetch_finra_margin()`：改为自动获取（FRED → 官网直抓 → 本地 CSV 历史补充），输出 YoY%、杠杆区间、增速回落信号。本地 `finra_margin.csv` 降级为可选历史补充，不再强制。
- **实测**：官网直抓返回 `1502.07 亿美元 / Jun-26`（与 ycharts 确认值 1.502T 一致 ✅）。
- **验收**：诊断页 Margin Debt 卡显示 `源: FRED MDEBT` 或 `源: FINRA官网直抓` + 官网交叉校验值。

### 1.3 期权 PCR 改个股级（utils.py + stock_dashboard.py）

**现状**：`utils.fetch_options_pcr()` 已对 `.HK/.SS/.SZ` 短路（yfinance 不覆盖港股/A股期权链）；`stock_dashboard.get_stock_put_call_ratio()` 用 Alpha Vantage `HISTORICAL_OPTIONS` 但只排除了 `.HK`。

**修复（已完成）**：`get_stock_put_call_ratio()` 短路条件从 `.HK` 扩展为 `symbol.endswith((".HK", ".SS", ".SZ"))`——Alpha Vantage HISTORICAL_OPTIONS 仅覆盖美股个股期权，港股/A股无免费源，明确标注"无免费源"而非误导性报错。
- **验收**：港股/A股个股深度分析页 PCR 区显示"当前数据源不覆盖港股/A股个股期权"；美股正常显示 Vol/OI PCR + IV。

### 1.4 SerpAPI 新闻无数据排查（utils.py + stock_dashboard.py）

**根因**（两个）：
1. SerpApi 免费额度（100/月）耗尽或限流时，`GoogleSearch.get_dict()` 返回 `{"error": ...}` 字段而非 `news_results`，原代码静默返回 `[]`。
2. `stock_dashboard.run()` 中新闻抓取 `if self.cfg.serpapi_key:` 才执行 → 未配置时 `news = {}`，新闻中心/个股页无数据。

**修复（已完成）**：
- `_serpapi_search()`：检测 `result.get("error")` 与 `search_information.organic_results_state == "Fully empty"`，命中即记录 warning 并返回 `[]`（不再静默）。
- `stock_dashboard.run()` 新闻段改用 `U.fetch_all_news_multi_source(...)`（多源聚合：SerpApi 可选 → Google News RSS → Finnhub/NewsAPI → Yahoo RSS → 东财 → 同花顺 → 雪球），**始终执行、始终有免费兜底**，news.json 不再依赖 SerpApi key。
- **验收**：无任何 key 配置时运行 `python stock_dashboard.py`，news.json 仍有政策/宏观/个股新闻（来自免费源）。

### 1.5 专业免费数据源调研（诊断页）

新增调研结论表（诊断页）：
- **FRED**（120/min，利率/杠杆）— 已接入
- **东方财富 push2**（无限制，A股/港股实时+K线+新闻）— 已接入

## 2. 风险管理层（risk.py — 新增）

### 2.1 positions.json（持仓记录）

```json
{
  "updated_at": "2026-08-05 14:00",
  "positions": {
    "0700.HK": { "buy_price": 320.5, "shares": 1000, "entry_date": "2026-08-01", "note": "腾讯中线" }
  }
}
```

API：`load_positions()` / `save_position()` / `delete_position()`（读写 `data/positions.json`，脏数据免疫）。

### 2.2 R 倍数分批止盈框架

`risk.r_multiple_plan(buy_price, stop_loss, current_price, atr, shares)`：
- **R = |buy − stop|**（单股风险）
- **+1R**：减仓 1/3，止损上移至成本价（保本）
- **+2R**：再减 1/3，止损上移至 +1R（锁定利润）
- **剩余 1/3**：移动止损追踪，趋势破位清仓
- 输出当前盈亏（% 与 R 数）、当前阶段提示、每档股数

**UI 落地**：个股深度分析页「交易策略」区，"止盈目标"卡改为"止盈逻辑: 分批减仓"，下方新增「R 倍数分批止盈（垫厚利润）」计划卡，并说明原逻辑（单一目标一次性了结易卖飞/回吐）。
- **验收**：任意有 sniper 理想买入+止损的个股，页面出现 +1R/+2R/剩余1/3 三档减仓计划与当前盈亏 R 数。

### 2.3 个股杠杆强平线

`risk.liquidation_line(entry, leverage, maintenance=0.3)`：
`强平价 = entry × (leverage−1) / (leverage × (1−maintenance))`
示例：2x 杠杆 + 30% 维持保证金 → 强平价 ≈ entry×0.714（跌 ~28.6% 触发强平）。`leverage_risk_plan()` 输出多档（1.5x/2x/3x）强平价 + 距强平 ATR 倍数 + 风险等级。与既有 `leverage_risk.json`（stock_dashboard 生成）互补。

### 2.4 宏观斩杀线

`risk.macro_kill_line(finra_margin_data)`：
| 融资 YoY | 级别 | 仓位上限 |
|---|---|---|
| > 60% | 极度危险 | ≤ 30% |
| 40–60% | 警戒 | ≤ 50% |
| 25–40% | 偏高 | ≤ 70% |
| ≤ 25% | 正常 | 100% |

增速回落（去杠杆）时上限上调 10pp。数据源即 1.2 节的 FINRA 自动抓取。
- **待办（未接线）**：在 Dashboard 宏观雷达或个股页展示 `macro_kill_line()` 输出（数据流已通，UI 挂接可下一步做）。

## 3. 选股三层架构（screener.py — 新增）

### 3.1 第一层 Universe Screening — 维科夫事件序列（纯计算）

`detect_wyckoff_events(df)`（需 OHLCV，≥120 根日K）：
- 识别 7 事件：**PS → SC → AR → ST → Spring → SOS → LPS**
  - PS：下跌中首次放量止跌（vol≥1.4x，跌幅收窄）
  - SC：巨量（≥1.8x）+ 长下影 + 大阴（恐慌高潮）
  - AR：SC 后放量反弹
  - ST：回踩前低 + 量缩（≤0.8x）
  - Spring：跌破 ST 低点快速收回（长下影 ≥ 1.5×实体）
  - SOS：放量（≥1.5x）长阳突破 60 日盘整上沿
  - LPS：SOS 后缩量回踩不破
- 置信度 = 事件数/7；阶段标签（初步支撑/吸筹早期/中期/后期/拉升突破）；趋势阶段（下跌/盘整/拉升）
- **纯 pandas 计算，无 LLM，可回测**

### 3.2 第二层 Multi-factor Scoring（纯计算）

`score_multi_factor(df, sector_df, sector_leader, bench_df, sector_syms)` 六因子：
- tech（均线结构 25%）+ POC 偏离（15%）+ 量能（15%）+ 板块联动（15%）+ 龙头强度（15%）+ 相对强度 RS（15%）
- 输出 0-100 综合分 + **60 分阈值**判断 + 因子明细（含 POC 价位与偏离%）

### 3.3 第三层 叙事生成（LLM 仅解释）

`build_screener_narrative_prompt(wyckoff, factors, symbol, name)`：把前两层结构化结果打包，Prompt 明确"只能解释输入，不得编造价格/消息/目标价"。`call_narrative_llm(prompt, llm_fn)` 由调用方注入 LLM 函数，无 LLM 时返回空串降级为结构化结论。
- **待办（未接线）**：将 `call_narrative_llm` 接到 DeepSeek 客户端（`utils._call_llm`），在个股页第三层叙事区块展示。

### 3.4 UI 落地（已完成）

- Dashboard 新增「🧬 维科夫吸筹扫描」区块：8 只美股标的，圆环置信度 + 阶段 + 事件数，展开看事件明细。
- 个股深度分析右侧新增「📐 多因子评分」（六因子雷达明细卡）与「🧬 维科夫吸筹」（圆环 + 阶段 + 事件序列）。

### 3.5 智能荐股升级（utils.recommend_stocks）

- **补相对强度 RS**：个股 ret20 相对全样本中位数的超额，权重 25%
- **PE 行业归一化**：按行业合理区间（半导体 15-35x、金融 6-15x、能源 8-18x…）线性映射；无行业用全样本中位数基准
- **权重重构**：tech 0.35 + val 0.20 + mom 0.20 + rs 0.25
- **增加建议买入价位**：`buy_zone`（保守 = min(last, MA20)；积极 = 现价−0.5×(现价−止损)；止损）
- `fetch_all_metrics` 顺带取 `sector` 字段（复用同一 .info 调用，不增加请求数）
- **验收**：Dashboard 荐股区条目出现 RS 分与买入区间；`strategy_meta` 含阈值 60 与权重说明。
