从「一个想法」到「一套系统」

我和 AI Agent 一起，把「私人股票看板」从零搭出来 · 全流程复盘汇报

网页版 + 手机小程序 + 每日自动数据流水线

1故事的起点：你想要什么

所有好系统的第一步，都是先把「想要的画面」讲清楚

你想要的，是这样一个东西：每天打开一个地方，就能看到——

  • 自选股今天涨了还是跌了、涨跌幅多少、是放量还是缩量；
  • 整个市场的情绪是贪婪还是恐慌；
  • 宏观上有哪些风险（美债、杠杆、恐慌指数）；
  • 值得关注的股票：理想买入价、二次加仓价、止损位、利好利空；
  • 每支股票最近的新闻在说什么、下周大概怎么走。

翻译成人话：你想雇一个「私人投研小团队」，每天收盘后帮你把市场捋一遍、把重点标出来。而我们的任务，就是把「这个想法」变成「两个能天天用的东西」：电脑上的网页版，和手机上的小程序版。

2第一步：先搭出「骨架」

先让它跑起来，再让它变好

🗂️ 网页版（指挥屏）

电脑打开即看全局：市场情绪 → 宏观 → 新闻 → 个股 → 交易策略，按分析师看盘顺序排版。

📱 手机小程序版（口袋版）

精简成重点卡：市场情绪、智能荐股、自选股、宏观风险雷达。

⚙️ 数据引擎

每天自动采集 41 只自选股（美股/港股/A股）+ 宏观指标 + 期权 PCR 数据。

🕐 定时任务

每天收盘后自动跑一遍、更新数据、生成日报，全程不用人管。

💡 这一阶段的核心价值：从 0 到 1 只花了一轮对话。以往这种「数据采集 + 网页展示 + 定时更新 + 手机端」的工程，从选型到联调往往要一个团队做几周；AI Agent 把骨架一次成型，剩下的时间全用来「打磨精度」。

3然后：你「挑毛病」，我「修毛病」

这是最花功夫、也是最值钱的阶段 —— 系统是在你的反驳里一点点变准的

🎯 标的名称校对反馈 1

「SKHY 是 SK 海力士，3750.HK 是宁德时代，不是 ETF。」—— 名称标错会影响所有分析判断，立刻在数据源里逐一核对修正。

🚨 价格错到离谱反馈 2 · 最关键

「7709.HK 今天暴涨 67%，你的系统却显示跌 22%，连符号都反了！」—— 挖出两层根因：历史数据用错了「复权」口径，且快照里把涨跌幅硬性封顶在 ±30%。修复为三家行情商实时交叉验证（腾讯 → 新浪 → 东方财富），并对 41 只股票逐个核对。

💥 网页白屏崩溃反馈 3

「网页打不开了，报 TypeError。」—— 定位到一个隐藏很深的 bug：数据缓存里「数字被存成了文本」，格式化时直接崩溃整页。修复后全站恢复正常。

📰 新闻要解读、要有预测、要有期权数据反馈 4

「新闻不能只罗列，要总结近 2 天说了什么；每支股票要有下周趋势；Vol/OI PCR（期权多空比）也要有。」—— 加了新闻解读器、下周走势预测全宽区、期权 PCR 专区。

🧹 新闻中心要专业反馈 5

「宏观/政策板块抓的都是社会新闻，政策板块完全是空的。」—— 加了金融相关性过滤（犯罪/娱乐/体育/天气一律剔除），给政策板块接上免费的权威新闻源（央行、证监会、国新办），实测抓到 8 条高质量政策新闻。

🔑 FRED 密钥「配了也没用」反馈 6

「我在 GitHub 里填了 FRED_API，怎么还提示没配置？」—— 发现两个系统各存各的密钥、互不相通；更意外的是，即便配对了，原来的代码根本没把图画出来。于是把「美债规模 × 杠杆联动图」真正补画了出来。

🌐 对外运营的细节反馈 7

「这网站要对外开放，别暴露内部信息。」—— 去掉数据源标注、把诊断入口移到角落、正式命名为 Investment Copilot · by Winnie。

6说人话总结

AI Agent 在这一程里到底帮了什么忙

AI Agent 在这里，像一位「啥都能干的助理」：

  • 听得懂人话——你把「想要什么」讲清楚，它就能变成网页、数据表、定时任务；
  • 能写代码、能查数据——从零搭出完整系统，还能实时核对行情、抓取新闻；
  • 会发现问题——白屏崩溃、数据失真、密钥不生效这类「藏起来的坑」，它逐个挖出来修掉；
  • 不厌其烦地改——你提一次意见，它改一版，直到你满意。

但请记住，方向和质量把关，始终是你在做。这一程最关键的转折点，几乎都来自你的一句话：「这个价格不对」「这个新闻没用」「数据一定要准」。系统之所以靠谱，是因为你认真把关；AI Agent 之所以有用，是因为它能听懂并执行你的把关意见。

💬 一句话版本：你出想法和标准，AI Agent 出力气和手艺，两个人（哦不，一人一机）把一个想法，做成了每天都能用的系统。
