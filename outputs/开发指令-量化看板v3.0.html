    2. 风险管理层（risk.py — 新增）

    2.1 positions.json（持仓记录）

    {  "updated_at": "2026-08-05 14:00",  "positions": {    "0700.HK": { "buy_price": 320.5, "shares": 1000, "entry_date": "2026-08-01", "note": "腾讯中线" }  }}

    API：load_positions() / save_position() / delete_position()（读写 data/positions.json，脏数据免疫）。

    2.2 R 倍数分批止盈框架

    risk.r_multiple_plan(buy_price, stop_loss, current_price, atr, shares)：

  • **R = |buy − stop|**（单股风险）
  • **+1R**：减仓 1/3，止损上移至成本价（保本）
  • **+2R**：再减 1/3，止损上移至 +1R（锁定利润）
  • **剩余 1/3**：移动止损追踪，趋势破位清仓
  • 输出当前盈亏（% 与 R 数）、当前阶段提示、每档股数

    • UI 落地：个股深度分析页「交易策略」区，"止盈目标"卡改为"止盈逻辑: 分批减仓"，下方新增「R 倍数分批止盈（垫厚利润）」计划卡，并说明原逻辑（单一目标一次性了结易卖飞/回吐）。

  • **验收**：任意有 sniper 理想买入+止损的个股，页面出现 +1R/+2R/剩余1/3 三档减仓计划与当前盈亏 R 数。

    • 2.3 个股杠杆强平线

    risk.liquidation_line(entry, leverage, maintenance=0.3)：

    强平价 = entry × (leverage−1) / (leverage × (1−maintenance))

    示例：2x 杠杆 + 30% 维持保证金 → 强平价 ≈ entry×0.714（跌 ~28.6% 触发强平）。leverage_risk_plan() 输出多档（1.5x/2x/3x）强平价 + 距强平 ATR 倍数 + 风险等级。与既有 leverage_risk.json（stock_dashboard 生成）互补。

    2.4 宏观斩杀线

    risk.macro_kill_line(finra_margin_data)：

    融资 YoY级别仓位上限
    ---------
    > 60%极度危险≤ 30%
    40–60%警戒≤ 50%
    25–40%偏高≤ 70%
    ≤ 25%正常100%

    增速回落（去杠杆）时上限上调 10pp。数据源即 1.2 节的 FINRA 自动抓取。

    3. 选股三层架构（screener.py — 新增）

    3.1 第一层 Universe Screening — 维科夫事件序列（纯计算）

    detect_wyckoff_events(df)（需 OHLCV，≥120 根日K）：

  • 识别 7 事件：**PS → SC → AR → ST → Spring → SOS → LPS**
  • - PS：下跌中首次放量止跌（vol≥1.4x，跌幅收窄）
  • - SC：巨量（≥1.8x）+ 长下影 + 大阴（恐慌高潮）
  • - AR：SC 后放量反弹
  • - ST：回踩前低 + 量缩（≤0.8x）
  • - Spring：跌破 ST 低点快速收回（长下影 ≥ 1.5×实体）
  • - SOS：放量（≥1.5x）长阳突破 60 日盘整上沿
  • - LPS：SOS 后缩量回踩不破
  • 置信度 = 事件数/7；阶段标签（初步支撑/吸筹早期/中期/后期/拉升突破）；趋势阶段（下跌/盘整/拉升）
  • **纯 pandas 计算，无 LLM，可回测**

    • 3.2 第二层 Multi-factor Scoring（纯计算）

    score_multi_factor(df, sector_df, sector_leader, bench_df, sector_syms) 六因子：

  • tech（均线结构 25%）+ POC 偏离（15%）+ 量能（15%）+ 板块联动（15%）+ 龙头强度（15%）+ 相对强度 RS（15%）
  • 输出 0-100 综合分 + **60 分阈值**判断 + 因子明细（含 POC 价位与偏离%）

    • 3.3 第三层 叙事生成（LLM 仅解释）

    build_screener_narrative_prompt(wyckoff, factors, symbol, name)：把前两层结构化结果打包，Prompt 明确"只能解释输入，不得编造价格/消息/目标价"。call_narrative_llm(prompt, llm_fn) 由调用方注入 LLM 函数，无 LLM 时返回空串降级为结构化结论。

  • **待办（未接线）**：将 `call_narrative_llm` 接到 DeepSeek 客户端（`utils._call_llm`），在个股页第三层叙事区块展示。

    • 3.4 UI 落地（已完成）

  • Dashboard 新增「🧬 维科夫吸筹扫描」区块：8 只美股标的，圆环置信度 + 阶段 + 事件数，展开看事件明细。
  • 个股深度分析右侧新增「📐 多因子评分」（六因子雷达明细卡）与「🧬 维科夫吸筹」（圆环 + 阶段 + 事件序列）。

    • 3.5 智能荐股升级（utils.recommend_stocks）

  • **补相对强度 RS**：个股 ret20 相对全样本中位数的超额，权重 25%
  • **PE 行业归一化**：按行业合理区间（半导体 15-35x、金融 6-15x、能源 8-18x…）线性映射；无行业用全样本中位数基准
  • **权重重构**：tech 0.35 + val 0.20 + mom 0.20 + rs 0.25
  • **增加建议买入价位**：`buy_zone`（保守 = min(last, MA20)；积极 = 现价−0.5×(现价−止损)；止损）
